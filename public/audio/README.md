# Audio de fondo

Ya incluye una pista en `background.mp3` (recodificada a 128kbps con fade
in/out para loopear sin corte, ~2.1 MB). Si quieres reemplazarla, coloca
aquí un archivo con el mismo nombre sobre el que tengas derechos de uso.

Recomendaciones si cambias el archivo:

- Duración: 1–3 minutos, en loop (el reproductor ya hace loop automático).
- Peso objetivo: menor a 3 MB para que la carga desde WhatsApp sea rápida.
- Volumen ya normalizado: el reproductor arranca en 35% de volumen.
- Si el archivo no existe, la invitación funciona igual: el control de
  música simplemente no aparece.
