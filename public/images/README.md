# Imágenes

Esta carpeta está lista para recibir:

- `og-image.jpg` (1200×630px): imagen de previsualización para WhatsApp,
  referenciada en `index.html`. Mientras no exista, algunas apps de
  mensajería mostrarán la preview sin imagen, sin romper el link.
- Cualquier fotografía o textura que se quiera incorporar más adelante
  a la sección de ubicación o al hero.

Ninguna imagen de stock quedó incluida en el repositorio: todo lo visual
por ahora se resuelve con tipografía, color y el motivo de línea dorada.
